## battleBusBot

Status:
Operacional

Responsabilidade atual:

* registrar informações dos jogadores da comunidade;
* armazenar nick do Fortnite;
* manter perfil de jogador vinculado ao usuário da plataforma.

Responsabilidades futuras:

* cadastro de preferências de jogo;
* questionário de perfil do jogador;
* busca de jogadores compatíveis;
* sistema de matchmaking;
* envio de notificações para formação de grupos.

Domínio principal:

Jogadores da comunidade.

Entidades esperadas:

* jogador
* perfil de jogo
* disponibilidade
* preferência de modos
* matchmaking

Integrações previstas:

* API Central FNBR
* sistema de notificações
* usuários da plataforma
